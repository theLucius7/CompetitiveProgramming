CompetitiveProgramming ​

theLucius7 的算法竞赛源码、模板与练习归档，以 C++ 为主，按 OJ 和比赛组织。

在线文档 / API 参考 · 在线题库 · 目录清单 · 贡献指南

分支 ​

分支内容
main算法源码、模板和已有开发工具
docs/project-guide文档站源码、API 契约、项目规范与构建检查；推送后自动发布
gh-pages题库网站、数据快照和生成的 docs/ 文档网站

文档无需合并到 main。推送 docs/project-guide 后，工作流构建文档并仅更新 gh-pages/docs/。源码清单记录所依据的主分支提交；刷新与部署方法见维护流程。

本地查看 ​

sh
git clone --branch docs/project-guide https://github.com/theLucius7/CompetitiveProgramming.git
cd CompetitiveProgramming
python3 scripts/docs.py check

文档可直接在 GitHub 或 Markdown 阅读器中浏览，无需启动网站或安装 Python 包。检查脚本需要 Git 和 Python 3.10+；单题编译需要对应语言的工具链，见快速开始。

本地运行文档网站需要 Node.js 22+：

sh
npm --prefix site ci
npm --prefix site run dev

预览地址为 http://127.0.0.1:4174/CompetitiveProgramming/docs/。OpenAPI 和 JSON Schema 下载入口位于 API 文档。

内容说明 ​

每份源码独立使用，没有全仓统一可执行程序。仓库包含未完成草稿和不带 main 的模板片段；文件存在、提交到 Git 或网页可见，都不代表已经通过 OJ。数量口径和记录基线见目录清单。

原题以对应 OJ 页面为准。仓库目前未声明统一的开源许可证，本文档未新增授权条款。
